Three resolved this frame, one dropped

  • Every goal carries four AprilTags. Red scoring is IDs 30 to 33, blue scoring 42 to 45.
  • For each tag it resolves, the Limelight gives a full 3D pose. We take the horizontal distance to it, in metres.
  • So one frame is a list of zero to four ranges. That list is the only input the brain gets.
  • Thirty frames a second. The camera alone tells us the range; the robot does not need to know where it is on the field for this.

Code: LimelightRanger.java is the only class that talks to the camera.

Point out that four tags means four independent measurements of the same distance. Averaging them is the first idea most students reach, and it is a good one. Also point out the dropped tag: the list is sometimes shorter, sometimes empty.
