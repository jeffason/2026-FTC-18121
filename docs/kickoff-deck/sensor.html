Three tags seen this frame, one missed

  • Every goal carries four AprilTags. Red scoring is IDs 30 to 33, blue scoring 42 to 45.
  • For each tag it sees clearly, the Limelight works out where that tag is in 3D. We keep one number: the distance to it along the floor, in metres.
  • So one frame is a list of zero to four ranges. That list is what the camera hands to the brain.
  • Thirty frames a second. The camera alone tells us the range; the robot does not need to know where it is on the field for this.

Code: LimelightRanger.java reads the camera.

Four tags means four separate measurements of the same distance, so averaging them is a good first idea. And one tag is missing here: the list is sometimes shorter, and sometimes empty.
