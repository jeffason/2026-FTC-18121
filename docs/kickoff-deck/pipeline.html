Every stage has a name, an on/off switch and a few tunables. Stages run in order; each sees the previous one's output.

No stages at all is the baseline: first tag, table value, fire every cycle.

Java: RangeFilter, VelocityModifier, FireGate interfaces · ShooterStages.java holds the built-ins

This is the one slide to remember. A stage is one idea with one job. Filters make the distance better, modifiers make the speed better, gates decide whether to shoot. Students add stages; they never edit the brain itself.
