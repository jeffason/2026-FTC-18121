Code 101

Words you will hear around the code

WordMeans
StageOne small piece of shooter logic with one job, and an on/off switch.
PipelineOur ordered list of stages. Not the Limelight's "pipeline", which is a camera setting.
TunableA number inside a stage you can change live, with a slider or the gamepad.
SpecThe one-line text that lists the stages and their tunables.
Unit testA tiny program that checks one piece of code gives the right answer. Runs on a laptop.
WordMeans
OpModeA program you pick and run on the robot. TeleOp means driver controlled.
Driver StationThe phone or tablet the driver holds. It shows our telemetry text.
BranchYour own copy of the code to change safely without touching anyone else's.
Pull requestAsking for your branch to be reviewed and merged into the shared code.
GradleThe build tool. It compiles the code and runs the tests when we type a command.

None of these need memorising tonight. They are here so the next three slides make sense.

The pipeline collision is worth saying out loud: Limelight has a setting called pipeline (which camera mode to run). Ours is a list of stages. If it ever gets confusing we can rename ours.
