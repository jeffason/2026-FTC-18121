README.md in that folder has the rest.

Only the two files in blue matter on day one. ShooterStages is where a new stage goes, and ShooterConfig is where your spec goes. The brain itself, ShooterBrain, is told what the camera saw every frame and decides the RPM and whether to fire every loop; it needs no robot, so it runs on a laptop. ShooterCalibration builds the real table from real shots and saves it on the robot. ShooterTeleOp drives, spins to target, and shows every stage's verdict on the driver's phone. That one command runs all 39 tests on your laptop in a few seconds, no robot needed. The README in that folder has more detail and every command.
