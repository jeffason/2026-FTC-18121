FileJob
ShooterStages.javaThe built-in stages and the registry. This is where you add yours.
Pipeline.javaOrdered stages, on/off switches, spec parsing, and what each stage did this loop.
ShooterBrain.javaobserve(tag ranges) every frame, evaluate(actual rpm) every loop. No SDK imports.
ShooterConfig.javaPIPELINE spec, calibration table, motor and camera names. The sim exports this file.
LimelightRanger.javaNew camera frame in, list of ranges to goal tags out. The only hardware-facing vision code.
ShooterCalibration.javaOpMode. Build the real distance to rpm table from real shots, save it on the hub.
ShooterTeleOp.javaOpMode. Drive, spin to target, request a shot, see every stage on the Driver Station.
ShooterBrainTest.javaTwenty-three automated tests that run on a laptop in seconds. No robot needed.
