The code, in one package

TeamCode/src/main/java/org/firstinspires/ftc/teamcode/shooter/

FileJob
ShooterStages.javaThe built-in stages and the registry, the list the code uses to find them. This is where you add yours.
ShooterBrain.javaobserve(tag ranges) every frame, evaluate(actual rpm) every loop. Uses no robot libraries, so it runs on a laptop.
ShooterConfig.javaPIPELINE spec, calibration table, motor and camera names. The sim exports this file.
ShooterCalibration.javaA robot program (an OpMode) that builds the real table from real shots and saves it on the robot.
ShooterTeleOp.javaThe driving program. Spin to target, request a shot, and see every stage's verdict on the driver's phone.
ShooterBrainTest.javaThirty-eight automated tests. One command runs them on a laptop in seconds, no robot: ./gradlew :TeamCode:testDebugUnitTest

From sim to robot: build and export, paste and send to the robot, calibrate, then drive. README.md in the package has the commands.

Only the two files in blue matter for day one: ShooterStages, where a new stage goes, and ShooterConfig, where the spec goes. The others support those two and are there when you need them.
