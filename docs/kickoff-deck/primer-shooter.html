Shooter 101

How a flywheel shooter works

1

A motor spins a wheel

That wheel is the flywheel. We tell the motor how fast to spin it, in revolutions per minute.

2

A ball touches the wheel

The feeder pushes a ball in. The wheel grabs it and throws it out. The wheel slows down a little each time.

3

Faster wheel, longer throw

The ball leaves at a speed set by the wheel. Farther goal means faster wheel. That is the one relationship everything else is built on.

QUESTION 1

How far is the goal?

QUESTION 2

How fast must the wheel spin?

QUESTION 3

Is now a good moment to shoot?

Every piece of code tonight answers one of these three questions. Remember the three colors.

If there is a flywheel on the bench, spin it up by hand and feed a ball. Students should see that a slow wheel throws short. Then ask the three questions and let them guess what a robot would need to answer each one.
