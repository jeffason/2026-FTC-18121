Shooter 101

How a flywheel shooter works

1

A motor spins a wheel

That wheel is the flywheel. We tell the motor how fast to spin it, in revolutions per minute.

2

A ball touches the wheel

The feeder, the part that pushes balls into the wheel, pushes one in. The wheel grabs it and throws it out, and slows down a little each time.

3

Faster wheel, longer throw

The ball leaves at a speed set by the wheel. Farther goal means faster wheel. That is the one relationship everything else is built on.

QUESTION 1

How far is the goal?

Answered by range filters: small switchable pieces of code that clean up the camera's distance reading

QUESTION 2

How fast must the wheel spin?

Answered by a velocity table (a list that turns distance into RPM), then by velocity modifiers that adjust that RPM

QUESTION 3

Is now a good moment to shoot?

Answered by fire gates: checks that can hold the shot until it is safe

Use the blue, violet and amber labels to tell which of the three jobs a piece of code does.

Watch the flywheel on the bench: spin it slowly and feed a ball, and it falls short. Spin it faster and it goes farther. Now guess what the robot would need to answer each of the three questions.
