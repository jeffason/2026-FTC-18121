From sim to robot

Build it in the sim

Prove it with the tests

Put it on the robot, calibrate once

4

Drive it

The sim tests the logic. Calibration gives the robot its real numbers.

Step one: build a pipeline in the sim, run it for 60 seconds in Wander, and write down the hit rate and shots per minute. Step two: if you wrote a new stage, add a test for it, then run all the tests with that one command; they pass in seconds on a laptop, no robot. Step three: copy the Java from the sim and paste it over ShooterConfig.java, build the project and send it to the robot, then run Shooter: Calibration once: five or six distances, A to record each point, Y to save. The table you measure on the robot replaces the sim's placeholder table. Step four: run Shooter: TeleOp. The right trigger spins the wheel, the right bumper asks for a shot, and the driver's phone shows every stage's verdict. Both halves have to happen before a range shot counts: the simulator for the logic, calibration for the numbers.
