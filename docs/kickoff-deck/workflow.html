From sim to robot

STEP 1

Build it in the sim

Add stages, tune, run 60 s in Wander. Record hit rate and shots per minute.

STEP 2

Prove it on the laptop

New stage? Add a test. Then run all the tests. They pass in seconds on a laptop, no robot.

STEP 3

Put it on the robot

Copy Java from the sim and paste it over ShooterConfig.java. Build the project and send it to the robot. Then run Shooter: Calibration once: five or six distances, A to record, Y to save.

STEP 4

Drive it

Run Shooter: TeleOp. Right trigger spins the wheel, right bumper asks for a shot, and the driver's phone shows every stage's verdict.

./gradlew :TeamCode:testDebugUnitTest

The table you measure on the robot replaces the sim's placeholder table.

The simulator is where you test the logic. Calibration is where the robot gets its real numbers. Both have to happen before a range shot counts.
