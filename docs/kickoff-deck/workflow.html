From sim to robot

STEP 1

Build it in the sim

Add stages, tune, run 60 s in Wander. Record hit rate and shots per minute.

STEP 2

Prove it on the laptop

New stage? Add a test. Then run the suite. Green in seconds, no robot.

STEP 3

Calibrate once

Run Shooter: Calibration. Five or six distances, A to record, Y to save. It prints the Java for the table.

STEP 4

Drive it

Shooter: TeleOp. Right trigger spins, right bumper requests a shot, the screen shows every stage's verdict.

./gradlew :TeamCode:testDebugUnitTest

Export from the sim, paste over ShooterConfig.java, build, deploy. The calibration table from the robot replaces the sim's placeholder.

The calibration OpMode is what makes the robot right. The sim's physics are placeholders. Say this twice: the sim is for the logic, the robot is for the numbers.
