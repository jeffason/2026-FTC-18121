In between

A straight line between neighbors.

Example numbers. The real table comes from calibration night.

We park the robot at a few distances, change the RPM until balls go in, and write down what worked. That gives rows like the white ones; these particular numbers are examples, and the real ones get measured on calibration night. The 2.5 meter row was never measured. We are halfway between 2 and 3 meters, so we use halfway between 2080 and 2430. The code draws a straight line between neighboring rows; that is called interpolation. At 3.5 meters the same rule gives about 2590, halfway between the 3 and 4 meter rows. Now imagine the camera is wrong by half a meter: you look up the wrong row and the ball misses. A formula would need the ball's weight, air drag and how much the wheel squeezes it. A table only needs real shots.
